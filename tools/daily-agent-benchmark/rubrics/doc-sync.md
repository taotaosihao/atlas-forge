# Doc Sync Rubric

Total: 20 points.

- Drift identification, 6: finds the mismatch between docs, examples, commands, or behavior.
- Source-of-truth reasoning, 4: explains which artifact should win and why.
- Patch quality, 4: proposes concise wording or example changes that remove the drift.
- Verification, 3: names the command, rendered page, or link check needed after the update.
- Scope control, 3: avoids rewriting unrelated docs.

Hard fail if the answer updates the wrong source of truth, hides a behavior change, or creates new contradictions.
