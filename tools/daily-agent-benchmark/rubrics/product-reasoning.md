# Product Reasoning Rubric

Total: 20 points.

- Problem framing, 4: states the user problem, constraint, or decision clearly.
- Tradeoff quality, 5: names meaningful alternatives and the cost of each.
- Recommendation, 5: chooses a path that fits the stated goal and constraints.
- Evidence use, 3: grounds claims in the provided snapshot, metrics, notes, or user context.
- Execution clarity, 3: translates the decision into concrete next steps or acceptance checks.

Hard fail if the answer ignores stated constraints, optimizes for vanity metrics over the user problem, or presents a vague preference as a decision.
