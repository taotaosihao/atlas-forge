# Data Check Rubric

Total: 20 points.

- Calculation accuracy, 8: recomputes the target metric correctly from the snapshot.
- Discrepancy detection, 4: identifies whether the reported value is correct and quantifies the gap.
- Evidence use, 3: shows the rows, fields, or arithmetic used.
- Recommendation, 3: proposes the smallest correction or follow-up.
- Communication, 2: clear result first, no unsupported assumptions.

Hard fail if the answer treats a wrong total as correct, invents missing data, or uses external data when the prompt says to use only the snapshot.
