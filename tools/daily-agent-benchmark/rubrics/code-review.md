# Code Review Rubric

Total: 20 points.

- Issue identification, 8: finds the highest-impact defect or regression, not just style issues.
- Impact reasoning, 4: explains concrete user, data, security, reliability, or maintenance risk.
- Fix quality, 4: proposes a small fix that addresses the root cause without broad unrelated changes.
- Evidence use, 2: cites snapshot files, functions, lines, commands, or observed behavior.
- Communication, 2: findings-first, concise, and actionable.

Hard fail if the answer says there are no meaningful issues when the oracle contains a critical bug, invents files outside the snapshot, or recommends unsafe behavior.
